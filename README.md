# Free Scripts

A place where I dump scripts and small projects that I’m fine sharing.

Most of it is open source. Some stuff stays private (personal projects, things I’m not ready to put out, or just stuff I don’t feel like maintaining). That’s just how it is.

If something here is useful to you, cool. If you spot a bug or me to improve something, feel free to join the [Discord](https://discord.gg/syncedd) server or message me privately. No promises on how fast I’ll look at it.

I’ll add more when I have something worth sharing.
